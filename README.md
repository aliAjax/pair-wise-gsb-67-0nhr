# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。
- 可追溯责任链：复核结论记录复核人、授权时段快照与适用设备；代理签署仅在授权范围内参与完整性判断。
- 证书换版、缺陷重开后依赖结论与签署批次立即级联失效；并发复核先到保留、后到待裁定。
- 保存中断按校验和与连续序号从最后一笔完整责任链恢复；旧数据迁移补出待确认授权，确认前不参与签署。

领域规则验证：`node --import jiti/register scripts/verify-chain.ts`（21 条断言）。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
